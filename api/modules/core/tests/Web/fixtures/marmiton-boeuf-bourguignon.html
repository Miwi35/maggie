Boeuf bourguignon : la vraie recette

Un grand classique de la cuisine bourguignonne, à préparer la veille pour le servir encore meilleur.

Ingrédients

  • 1,2 kg de boeuf à braiser
  • 150 g de lardons
  • 2 oignons

Préparation

Faire revenir les lardons puis les morceaux de boeuf. Laisser mijoter à feu doux pendant 3 heures.
