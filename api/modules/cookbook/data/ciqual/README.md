# Ciqual Food Composition Database

## Source

- **Dataset**: Table de composition nutritionnelle des aliments Ciqual
- **URL**: https://entrepot.recherche.data.gouv.fr/dataset.xhtml?persistentId=doi:10.57745/RDMHWY
- **DOI**: 10.57745/RDMHWY
- **Version**: 2025-11-03
